# AWS 보안 사고 대응 대시보드 (Streamlit)

## 설치와 실행

프로젝트 루트(`SeSAC_3rd_Project/`)에서:

```bash
uv add "streamlit>=1.44"
uv run streamlit run frontend/app.py
```

## 파일 배치

```
SeSAC_3rd_Project/
├── .streamlit/config.toml   # 테마 (파란 버튼, 밝은 배경)
└── frontend/
    ├── app.py               # 화면
    ├── services.py          # 백엔드 연결 (분석 실행, 보안상 주의사항, 결과 저장)
    └── ui.py                # 카드·배너·타임라인 등 화면 조각과 스타일
```

## 화면

| 메뉴 | 내용 |
| --- | --- |
| 대시보드 | 시연 모드. 팀 시연 자료를 단계별로 재생. 요약 화면: 문제되는 곳·단계·숫자 요약 → 조사 대상 사건(크게) → 분석 영역별 탐지 / 타임라인(단계가 갈수록 쌓임). 상세보기: 단계 설명 → 요약 → 보안상 주의사항 → 후보 사건 → 참고 문서 → 해석 주의점 → 운영 상태 집계 → 보고서 받기 → 근거 로그 위치 |
| 홈 | 가장 위험한 사건 배너, 서버·네트워크 상황(관측된 이상 징후 대상·탐지·높음 이상 수), Log 조사 내용, 보안상 주의사항, 타임라인, 참고 문서 |
| 사고 분석 | 이벤트 파일과 범위를 정해 분석 실행, 저장한 결과 JSON 불러오기, 이번 세션의 분석 전환 |
| 분석 기록 | 탐지 목록(필터·검색). 행을 누르면 사건 상세: Log 조사 내용, 주요 로그 원문, 추가 조사 결과, 보안상 주의사항, 참고 문서, 타임라인 |
| 보안 매뉴얼 | 보안 매뉴얼에 직접 질문 (사건 상세의 "이어서 질문하기"로 질문 자동 채움) |
| 설정 | 결과 JSON 저장, **대시보드(시연 모드) 메뉴 표시 켜기/끄기**, 연결 상태 확인, 세션 초기화 |

## 기준

- 위험 단계(4단계): 낮음 1 · 주의 2 · 높음 3 · 긴급 4 (Finding.severity low/medium/high/critical 그대로). 탐지가 없으면 '탐지 없음'(회색)으로 표시하고 '정상'이라고 말하지 않는다
- 서버·네트워크 상황: 그 분석 영역이 실제로 관측한 값만 센다(이상 징후 대상 수, 탐지 수, 높음·긴급 수). 정상/경고/장애로 판정하지 않는다 - 이 시스템은 이상 징후만 관측하고 심각도 기준이 탐지기마다 달라서다(팀 report/models.py OPERATIONAL_STATE_POLICY)
- 보안상 주의사항: 성능(performance)·자원(resource) 이상은 보안 사고로 판단된 바가 없으므로 매뉴얼을 검색하지 않고 그 이유를 보여준다(팀 방침). 그 밖의 사건은 내용으로 보안 매뉴얼(RAG)을 검색해 만들고, 분석 결과에 함께 저장. 결과 JSON 을 저장해 두면 발표 때 네트워크 없이 보여줄 수 있다

## 시연 모드

사이드바의 "대시보드" 메뉴에서 실행한다. 설정의 "대시보드(시연 모드) 메뉴 표시"로 메뉴를 숨기거나 보일 수 있다(기본: 보임).
팀 시연 자료(output/demo/<시나리오>/manifest.json + step_00~06)를 단계별로 재생하며, 이전/다음/자동 재생(권장 시간 간격)과
마지막 단계의 최종 보고서 JSON 받기를 제공한다. 외부 API 는 호출하지 않는다.
메뉴 표시 여부는 output/frontend_settings.json 에 저장되어 새로고침해도 유지된다.

### 자료 준비

시연 자료는 `output/` 아래에 만들어지며 git 에 올라가지 않는다. 둘 중 하나로 준비한다.

1. 자료를 만든 팀원에게 `output/demo/` 폴더를 받아 프로젝트 루트의 `output/demo/` 에 그대로 넣는다.
2. 분석 결과(`output/reports/*.json`, `output/findings/*.pkl`)가 있는 PC 에서 직접 만든다.

```bash
uv run python scripts/build_demo_replay.py --all
```

자료가 없으면 대시보드 화면에 이 안내가 나온다.
